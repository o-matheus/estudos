## Como o curso se organiza

O curso é dividido em **boxes** (preparação, experimentação e estruturação do projeto) e **circuitos** (com dificuldade gradativa). A numeração das aulas indica a posição no curso, não dias de estudo nem datas.

👉 **Progresso e índice das aulas:** [anotacoes/README.md](anotacoes/README.md)

## Sincronização

As anotações são escritas no repositório `clone-tabnews-ia` (`~/ti/curso.dev/clone-tabnews-ia/anotacoes/`) e copiadas para cá com o script [`scripts/sincronizar-curso-dev-ia.sh`](../../scripts/sincronizar-curso-dev-ia.sh).
A fonte é o `clone-tabnews-ia`: edite as notas lá, não aqui, senão a próxima cópia sobrescreve a mudança.

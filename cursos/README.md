## Como organizar um curso

```
cursos/
└── nome-do-curso/
    ├── README.md        ← ficha + índice do curso (template: _templates/curso.md)
    ├── AGENTS.md        ← opcional: regras para assistentes de IA específicas do curso
    └── anotacoes/       ← uma nota por aula, módulo ou dia (como o curso se organizar)
```

Código de exercícios pequenos pode ficar em `codigo/` dentro do curso. Projetos maiores ganham repositório próprio e uma ficha em [projetos/](../projetos/README.md).

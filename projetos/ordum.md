# Ordum

- **Repositório:** https://github.com/forgestack-team/ordum
- **Contexto:** grupo de estudo (ForgeStack)
- **Stack:** Java 21, Spring Boot 4.1.2, Gradle · Angular 22 (standalone) · PostgreSQL 18 via Docker Compose · Flyway · Makefile
- **Status:** 🟢 Sprint 1 — Infraestrutura e Bootstrap (situação em 10/11/2026)

## O que é
Aplicativo de finanças pessoais construído pelo grupo para aprender com um projeto de ponta a ponta. O MVP cobre contas, categorias, receitas/despesas com data prevista, saldo atual e previsto, recorrências mensais, transferências entre contas e filtros. Autenticação e contas de usuários ficam para depois.

## Situação
- ✅ Infra: PostgreSQL 18 via Docker Compose, healthcheck e `.env.example`
- ✅ Backend: bootstrap Spring Boot, pacotes base, endpoint `GET /api/v1/ping`
- 🔄 Frontend: bootstrap Angular na branch `feature/frontend`
- ⏳ Migrações Flyway e Makefile

# Clone TabNews

- **Repositório:** https://github.com/o-matheus/clone-tabnews
- **Contexto:** curso — [curso.dev Programação Web](../cursos/curso-dev-programacao-web/README.md)
- **Stack:** Node.js (lts/hydrogen via `.nvmrc`), Next.js 13.1.6 (Pages Router), React 18.2.0
- **Status:** 🟢 em andamento (acompanha o curso; última atualização no dia 004)

## O que é
Projeto construído ao longo do curso.dev: um clone do TabNews, feito de forma incremental a cada dia de aula.

## O que aprendi
- Fixar a versão do Node por projeto com `.nvmrc` + `nvm use`
- `package.json` × `package-lock.json`
- Rotas baseadas em arquivos (`pages/`) e `npm run dev`
- Expor o servidor local com port forwarding do VS Code

## Problemas que resolvi (e como)
- Conflito `ERESOLVE` no npm → apagar `node_modules` e o lockfile e reinstalar as versões do curso ([detalhes no dia 003](../cursos/curso-dev-programacao-web/anotacoes/dia-003.md))

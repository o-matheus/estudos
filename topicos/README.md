# 🧠 Tópicos

Base de conhecimento organizada **por tema**, independente de onde aprendi.

Use para:
- conteúdo avulso (artigos, vídeos, livros, documentação);
- consolidar um assunto que aparece em vários cursos/disciplinas, com links para as notas de origem.

Exemplos de temas: `git`, `sql`, `algoritmos`, `javascript`, `arquitetura-de-software`, `testes`, `carreira`.

Cada tema é uma pasta com um `README.md` (template: `_templates/topico.md`) e quantas notas precisar.

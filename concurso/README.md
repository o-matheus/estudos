## Como cada concurso é organizado

```
concurso/
└── AAAA/                        ← ano da prova
    └── nome-do-concurso/
        ├── README.md            ← ficha: banca, datas, vagas, regras da prova, links
        ├── AGENTS.md            ← regras para assistentes de IA
        ├── edital/              ← PDFs do edital (só no computador; o Git ignora PDFs)
        ├── conteudo-base/       ← material de estudo pesquisado/gerado, um arquivo por disciplina
        └── anotacoes/           ← minhas anotações, uma por dia de estudo (AAAA-MM-DD.md)
```

- **Conteúdo base** = o material de referência (pesquisado na internet ou gerado com IA) que uso para estudar, organizado pelo conteúdo programático do edital.
- **Anotações** = o que **eu** entendi, com as minhas palavras, registrado por dia. Correções ficam numa seção separada, para eu ver onde errei.
